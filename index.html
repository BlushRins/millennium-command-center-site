Millennium Command Center

A personal desktop dashboard for one student's Linux setup.

Millennium Command Center is a full-screen dashboard that runs locally on its owner's computer. One of its panels shows upcoming events from Google Calendar, Google Classroom class calendars, and Canvas.

It is a personal tool, not a public service. It has no servers, no accounts, and no users other than its developer.

Google Calendar access

The dashboard asks Google for read-only calendar access (calendar.readonly) so it can list upcoming events. It cannot create, change, or delete anything. See the privacy policy for exactly what is read and where it is kept.
