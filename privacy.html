Privacy Policy

Millennium Command Center · Last updated October 26, 2026

Who uses this app

Millennium Command Center is a personal dashboard used only by its developer on their own computer. It is not offered to the public.

What Google data it accesses

With your permission, the app uses the Google Calendar API with the read-only scope https://www.googleapis.com/auth/calendar.readonly. It reads the list of your calendars and the upcoming events on the calendars you choose to show. It cannot create, edit, or delete events.

What it keeps

  • Sign-in token. The Google OAuth token is saved in a file on the local computer so the dashboard can refresh events.
  • Event cache. A small local cache holds only what the dashboard displays: event title, start and end time, location, a link, and which calendar it came from. Raw responses from Google are never written to disk.

Both stay on the local computer. Nothing is uploaded to any server.

Sharing

Google user data is not sold, shared with, or transferred to anyone. It is not used for advertising or to train AI or machine-learning models. Its use follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

You can revoke access at any time at myaccount.google.com/permissions. Running millennium-calendar disconnect deletes the local token and event cache.

Contact

Questions: open an issue at github.com/BlushRins/millennium-command-center-site.
